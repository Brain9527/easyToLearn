# 简单学（English Learning）

基于 Preact + TypeScript + Vite 的英语词汇学习 Web 应用。所有数据保存在本地浏览器（IndexedDB），无需后端，不上传任何词库。可选的 AI 在线生成功能需要用户自行提供 DeepSeek API Key。

## 环境要求

- Node.js 18 及以上（已在 Node 22 下验证）
- npm 9 及以上
- 现代浏览器（Chrome / Edge / Safari / Firefox），需支持 IndexedDB；发音依赖浏览器 SpeechSynthesis

## 安装与运行

```bash
npm install        # 安装依赖
npm run dev        # 启动开发服务器，默认 http://localhost:5173
npm run build      # 类型检查（tsc --noEmit）+ 生产构建，输出到 dist/
npx vite preview   # 本地预览生产构建
npm test           # 运行全部自动化测试（Vitest + jsdom + fake-indexeddb）
```

## 功能与使用说明

### 1. 单词列表
- 展示英文、音标与谐音（谐音显示在音标下方的一个合并列）、发音按钮、中文释义、学习状态和操作。
- 表格字体整体略小、行高保持舒适；在同一行操作列中点击“详情”展开时，详情内容会以浮层形式出现在该行下方，不再挤占同行“练习/编辑/详情”按钮位置。
- 支持按英文、释义或谐音搜索（忽略大小写和首尾空格）；可按学习状态、是否为错题筛选；可按添加时间或英文排序；一键清空条件。
- 支持手动添加、编辑、查看详情和删除单词。**删除单词会一并删除其学习记录、错题记录和答题日志**，确认弹窗中会说明这一点。
- 点击“练习”可直接进入该单词的练习。
- 可将全部词库或当前筛选结果导出为 `.xlsx`，同时可用作备份。

### 2. Excel 导入（右侧栏“导入词库”）
1. 选择 `.xlsx`、`.xls` 或 `.csv` 文件；
2. 解析表头，预览前几行；
3. 自动识别列映射（同义列名见下表），可在下拉框中手动修正；
4. 校验：英文为空的行报告行号、字段和原因，完全空白的行自动跳过，文件内部重复和与词库重复都会识别（忽略大小写，保留短语内部空格）；
5. 已存在单词的处理策略：**跳过**、**覆盖**或**仅补充空字段**；
6. 显示统计：总行数、有效行、将导入数、跳过数、重复数、错误数；
7. 确认后在**一个 IndexedDB 事务**中写入。任一条写入失败时整批回滚；取消导入不会改动词库。

| 字段 | 可识别的列名 |
| --- | --- |
| word | word、英文、英语、单词、词汇、English |
| phonetic | phonetic、音标、国际音标、IPA |
| meaning | meaning、中文、中文意思、中文释义、释义、翻译 |
| mnemonic | mnemonic、谐音、中文谐音、发音谐音、记忆提示 |
| example | example、例句、英文例句 |
| exampleMeaning | exampleMeaning、例句翻译、中文例句 |
| notes | notes、备注 |

可通过“下载模板”获取标准模板，其中包含一行 `Hello!` 示例。示例只存在于模板中，不会写入词库。

#### 内置词汇
在“导入词库”中把来源切换为 **内置词汇**，点击“打开内置词库”，即可从 `public/libraries/` 中的内置词库多选导入，重复单词自动跳过。

#### AI 在线生成（DeepSeek）
在“导入词库”中把来源切换为 **AI 在线生成**：
1. 先在右侧栏“AI 在线生成设置”中填写自己的 DeepSeek API Key，可选择模型 `deepseek-chat`（默认）或 `deepseek-reasoner`；
2. **按主题生成**：填写主题，选择数量（10/20/30/50）和难度；**补全已有单词**：粘贴单词或短语（每行一个或用逗号分隔，最多 100 个），AI 会补全音标、释义、谐音和例句；
3. 生成结果会进入与 Excel 相同的映射、校验、去重、预览和确认流程，**确认之前不会写入词库**，生成过程中也可以随时取消。

隐私与费用：Key 只保存在本机 IndexedDB 中，由浏览器直接请求 `api.deepseek.com`，不经过任何其他服务器；请求中只包含主题或你输入的单词，不包含词库和学习记录。调用费用由你的 DeepSeek 账户承担。AI 生成的内容可能有误，请在预览中核对。这是本应用唯一的联网功能，不配置 Key 时完全离线可用。

### 3. 学习
- 题目区显示中文释义、发音按钮，以及“音标与谐音”块（音标在上，谐音在下方），可通过一个开关统一控制显示。**不会显示英文答案**。
- 可设置：每轮题量（10/20/50/全部，超出可学词数时自动取实际数量）、学习范围（全部/未掌握/错题）、题目顺序（顺序/随机）、是否自动播放发音、是否播放正确音效、是否显示“音标与谐音”、是否开启“肌肉记忆学习”。
- **肌肉记忆学习**：开启后会直接显示完整单词，供用户照着输入；该模式下不计入“首次答对”，也不会加入错题本。
- **多单词答题的空格自动补全**：答案为短语（例如 `hello world`）时，用户输入到空格位置会自动跳过并补上空格，无需手动打空格；手动输入的多余末尾空格会被自动去除。
- **答对**：输入框显示成功状态，并播放约 450ms 的动画和本地合成的提示音（Web Audio，可关闭），随后自动进入下一题。
- **答错**：提示“回答错误，请重新输入”，显示你刚才的输入，清空输入框并重新聚焦，题目保持不变，同时自动加入错题本。同一单词多次答错只更新同一条错题记录。
- **第二次及以后答错**：按单词逐个比对，只把拼错的那个单词标红并闪动提示（如答案 `hello world` 输入 `hello wrold`，仅 `world` 标红）。
- **手机 / iPad 适配**：触屏设备没有回车键，输入框填满后会**自动提交**，并隐藏“提交”按钮；题目之间键盘不会收起。手机上答题槽字号随屏宽缩放，操作按钮改为三列、触控区域不小于 44px。电脑端仍按 Enter 或点击“提交”。
- **提示**：依次显示首字母、单词长度、部分字母、重播发音、例句（例句中的答案会被遮盖）。
- **显示答案**：需要用户主动点击，该操作会被记录；之后即使答对，也不计为首次答对。
- **跳过 / 退出本轮**：可随时使用。
- **本轮结束统计**：总题数、首次答对、曾经答错题数、总错误次数、正确率、新增错题数，并提供继续学习、重练错题、返回单词列表三个入口。

### 4. 错题本
- 学习中答错会自动收录，无需手动维护。
- 展示英文、音标、释义、谐音、累计错误次数、最近错误时间、最近错误答案、复习次数、状态和连续答对进度。
- 复习范围：全部、最近错误、高频错误优先、仅待复习；可按错误次数或最近错误时间排序。
- 复习与学习模式共用同一套判题逻辑、输入组件和反馈。
- 不提供硬删除，只能标记为已掌握、重新加入待复习、隐藏已掌握或查看错误历史。

### 5. 设置与统计（右侧栏）
- 可选择英语语音（按英式、美式和其他英语口音分组），语速可调，默认 0.9，推荐 0.85～0.95；可试听当前语音。
- 可开关“判题时忽略标点”，并可清空全部本地数据（需二次确认）。
- 所有设置保存在 IndexedDB，刷新后仍然有效。

## 业务规则与统计口径

### 答案判定规则
1. 去除首尾空白；
2. 忽略大小写；
3. **不忽略单词内部空格**（`look after` ≠ `lookafter`），不做拼写纠错；
4. **默认不忽略标点**：词库中是 `Hello!` 时，输入 `hello` 判错，必须输入 `hello!`；
5. 在设置中开启“判题时忽略标点”后，比较前会先去掉两边的 `. , / # ! $ % ^ & * ; : { } = - _ \` ~ ( ) ? " ' [ ] \ | + < >` 等 ASCII 标点。

实现见 `src/features/learning/answerNormalizer.ts`。

### 掌握规则
- **错题掌握**：在**不同复习回合**（以 sessionId 区分）中连续独立答对 3 次，才会标记为“已掌握”。同一回合内重复答对只算一次；再次答错时连续次数清零，状态回到“复习中”。
- **独立答对**：本题中没有答错、没有显示答案、没有跳过。
- **单词学习状态**：未学习 → 学习中 / 需复习 → 已掌握（在不同回合中连续独立答对 3 次即为已掌握；有答错记录且尚未达标时为“需复习”）。

### 统计口径
- **首次答对**：本轮中没有答错、没有显示答案、没有跳过就答对的题数；答错后再答对不计入。
- **本轮正确率**：首次答对题数 ÷ 本轮总题数。
- **今日正确率**：今日答对的提交次数 ÷ 今日全部提交次数（不含跳过和显示答案）。分母是提交次数，不是单词数量。
- **今日学习数量**：今日有答题记录的不同单词数。
- 所有统计都根据 IndexedDB 中的学习记录、错题记录和答题日志实时计算。

## 发音说明
- 发音使用浏览器原生 SpeechSynthesis 合成语音，属于“合成语音”，**不是真人录音**。不同系统和浏览器的音色、口音不同。
- 应用会优先选择英语语音；如果浏览器不支持语音合成或播放失败，会给出提示，此时可以参考 IPA 和谐音学习。
- 只有用户主动操作才会播放发音；开启“自动播放发音”后，每道题也只播放一次。
- 谐音仅用于辅助记忆，不能替代标准发音和 IPA。

## 数据存储
- IndexedDB 数据库名为 `easy-learn-db`。包含 vocabularies、studyRecords、wrongQuestions、settings、attemptLogs 等存储，版本迁移逻辑位于 `src/db/migrations.ts`。
- 批量导入、级联删除和答题记录写入均使用多 store 事务。
- 当浏览器不支持 IndexedDB 或写入失败时，界面会显示明确的错误信息，并提供重试入口。

## 已知限制
- 合成语音的质量取决于设备；部分浏览器可能没有英式或美式英语语音。
- `xlsx` 库体积较大，生产包主 chunk 约 500KB（gzip 后约 170KB），构建时会出现 chunk 体积警告。
- 数据只保存在当前浏览器中。清除浏览器数据会丢失词库，请定期导出备份。

## 部署到 GitHub Pages（自动部署）

项目已内置 GitHub Actions 工作流 `.github/workflows/deploy.yml`，推送到 `main` 分支即自动构建并发布到 GitHub Pages。

启用步骤：
1. 把代码推送到 GitHub 仓库（仓库名 `easyToLearn`，默认分支 `main`）；
2. 打开仓库 **Settings → Pages**，在 **Build and deployment → Source** 中选择 **GitHub Actions**（而不是 Deploy from a branch）；
3. 首次推送后，Actions 页会出现 `Deploy to GitHub Pages` 任务；完成后站点访问地址为 `https://<user>.github.io/easyToLearn/`。
4. 之后每次 `git push origin main` 都会自动重新部署；也可以在 Actions 页手动触发 `Run workflow`。

关于路径：`vite.config.ts` 中 `base` 已显式设为 `'/easyToLearn/'`，对应仓库同名子路径。若后续想绑定自定义域名或改仓库名，相应调整 `base` 并在 `public/CNAME` 写入域名即可。

工作流做了什么：安装依赖（`npm ci`）→ 运行测试（`npm test`）→ 构建（`npm run build`）→ 复制 `index.html` 为 `404.html`（避免直链访问出现 404）→ 上传 `dist` 并通过 `actions/deploy-pages` 发布。

- **单词列表合并列**：单词列表的「音标」和「中文谐音」两列合并为「音标与谐音」一列，谐音以次要文字显示在音标下方；表格字体整体略小、保持舒适的行高。
